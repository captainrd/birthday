# For Niku — Final Romantic Birthday Story Website

This is the final story-focused version, with personal chapters rewritten from the memories Rohan shared, a romantic blush/rose/ivory aesthetic, all supplied photos in the Memories gallery, a Braj Yatra chapter, and a birthday letter.

## Run locally
1. Extract this ZIP.
2. Open `NikuBirthday-Complete/index.html` in a browser, or use VS Code Live Server.
3. Keep the `assets` folder beside the HTML files.

## Pages
- `index.html` — romantic opening
- `chapter-one.html` — Cloud Computing lab and first conversations
- `chapter-two.html` — all-night chat, Aksa Beach, becoming a couple, and Ganu
- `chapter-three.html` — family rejection, distance, placement, and Akkalkot
- `chapter-four.html` — the rose in the auto on 7 February 2025
- `memories.html` — photo gallery
- `braj-yatra.html` — five days in Braj
- `birthday-letter.html` — personal birthday letter and reveal

Only photos are included; no video files are bundled. Google Fonts load online, with fallback fonts available offline.
